# sidchan.dev — Developer Portfolio

Personal developer portfolio for **Siddharth Chandran**, built with vanilla HTML, CSS, JavaScript (ES modules), [Vite](https://vitejs.dev/), [GSAP](https://gsap.com/), and [Vercel Analytics](https://vercel.com/analytics).

## Highlights

- **Light-First Editorial Design with Optional Dark Mode**: Defaults to a warm light stone palette (`#f6f5f0`) with an optional high-contrast dark theme (`#0a0d0c`), persisted via `localStorage` (`sidchan-theme`) and applied pre-paint to avoid flash of unstyled content.
- **Filterable Project Showcase**: Interactive era filters (`All`, `The AI Era`, `Foundations`) with polite `aria-live` announcements:
  - **The AI Era**: [Antigravity Model Usage](https://github.com/Siddharth-Chandran/antigravity-model-usage), [Smart Chrome Calculator](https://chromewebstore.google.com/detail/smart-glass-calculator/ccilhokinjiabjciaahelojbkindneni), and [Save the Date: Rohit](https://samrohit.live/)
  - **Foundations**: [Wego Parking Problem](https://github.com/Siddharth-Chandran/wego-parking-problem), [CSV Uploader](https://github.com/Siddharth-Chandran/csv-uploader), [CPI Dashboard](https://github.com/Siddharth-Chandran/cpi-dashboard), and [OCR System](https://github.com/Siddharth-Chandran/OCR)
- **Accessible Navigation & Micro-Interactions**: Scrollspy navigation, a native `<dialog>` mobile drawer with focus management, click-to-copy email (`sidchan@duck.com`) with a `popover="manual"` toast notification, and `prefers-reduced-motion`-aware GSAP + ScrollTrigger entrance animations.

## Tech Stack

- **Build Tool**: Vite 5 (`vite`)
- **Frontend**: Semantic HTML5, CSS Custom Properties (`Bricolage Grotesque`, `Manrope`, `JetBrains Mono`), Vanilla JavaScript (ES Modules)
- **Motion**: GSAP (`gsap` + `ScrollTrigger`)
- **Analytics**: `@vercel/analytics`

## Project Structure

```text
dev-portfolio/
├── index.html       # Semantic page markup, SVG schematics, and pre-paint theme script
├── style.css        # Design tokens (light default + dark theme), responsive grid, and motion styles
├── main.js          # Theme toggle, mobile drawer, scrollspy, project filters, copy toast, and analytics
├── animations.js    # GSAP hero entrance, ScrollTrigger reveals, and reduced-motion handling
├── dist/            # Production build output generated by Vite
└── package.json     # Dependencies and npm scripts
```

## Getting Started

```bash
# Install dependencies
npm install

# Start the local development server
npm run dev

# Build for production (outputs to dist/)
npm run build

# Preview the production build locally
npm run preview
```

## Deployment

`npm run build` compiles the static site into `dist/`, ready for static hosting on Vercel (with `@vercel/analytics` enabled) or GitHub Pages.
